# 🎉 VIBRANCE 2026 – College Cultural Event Website

A modern, responsive college cultural festival website built using **HTML5 and CSS3**. The website showcases event details, schedules, performers, venue information, and a registration section.

## 🌐 Live Demo

**Visit Website:** https://bhanumadhavm-design.github.io/college-event/

## 📌 About the Project

VIBRANCE 2026 is a college cultural fest website designed to provide students with information about an exciting college festival.

The website features an attractive user interface with a modern dark theme, vibrant gradient colors, and responsive layouts.

## ✨ Features

- **Home Section:** Eye-catching hero section with event details.
- **About Section:** Introduction to the cultural festival.
- **Event Schedule:** Displays the event timings and activities.
- **Featured Performers:** Showcases performers with images and descriptions.
- **Venue Section:** Displays event location and Google Maps directions.
- **Registration Section:** Includes a registration form for participants.
- **Responsive Design:** Supports desktop, tablet, and mobile screens.
- **Smooth Navigation:** Easy navigation between different sections.
- **Modern UI:** Gradient backgrounds, hover effects, and attractive styling.

## 🚀 How to Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/bhanumadhavm-design/college-event.git
   ```

2. Open the project folder:

   ```bash
   cd college-event
   ```

3. Open the `index.html` file in your browser.

4. Alternatively, use the Live Server extension in VS Code.
